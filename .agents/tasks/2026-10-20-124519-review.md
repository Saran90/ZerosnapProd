# MRZ scanner dependency removal

The app drops the `mrzscanner_flutter` SDK and migrates all passport/visa scanning to OCR-based extraction. MRZ scanning code, entities, and UI components are deleted. The scanByMrz server flag and all conditional branching between MRZ and OCR flows are removed. Three scan pages were already rewritten to use a camera-capture-then-extract pattern; this change removes the last MRZ references and simplifies the card-selection dialog. Firebase integration, theme updates, and CI workflow additions arrived in the same branch but are unrelated to the MRZ removal.

**Watch for:** The login endpoint remains `/api/MRZauthenticate` (not a concern—deliberate decision per commit `40f5232`). No blocking issues remain.

**Verdict**: APPROVED

## High-level view

The three MRZ-specific files (mrz_result.dart, mrz_scanner_page.dart, mrz_result_sheet.dart) are deleted. The mrzscanner_flutter dependency is removed from pubspec.yaml, and the license key registration call is removed from main.dart. The choose_card_dialog.dart no longer imports mrzscanner_flutter or calls MRZ scanner functions—helper functions for MRZ camera/gallery scanning are deleted, and all passport flows now use the OCR-based scan pages. The scanByMrz field is fully removed from shared_preferences_provider.dart, LoginSession, MobileSettings, auth_repository.dart, and frro_credentials_page.dart—no code reads or writes this flag anymore. The GitHub Actions workflow is new (not modified) so no MRZ-related CI patches are present. OCR-based scan pages (domestic_card_scan_page.dart, domestic_passport_scan_page.dart, foreign_passport_scan_page.dart, and the existing passport_card_scan_page.dart) remain intact. The diff includes unrelated changes (Firebase integration, theme rebrand, app icon updates, CI workflow) that arrived in the same branch but don't interact with the MRZ removal.

## MRZ files deleted

The three MRZ-specific files are fully deleted:

- `lib/features/scan/domain/entities/mrz_result.dart` (154 lines) — entity model for MRZ scan results, with JSON deserialization matching the Android project's format.
- `lib/features/scan/presentation/pages/mrz_scanner_page.dart` (277 lines) — wrapper page that configured the mrzscanner_flutter plugin and launched camera or gallery scanning, with separate modes for passport vs. visa.
- `lib/features/scan/presentation/widgets/mrz_result_sheet.dart` (251 lines) — bottom sheet displaying MRZ scan results with portrait image, extracted fields, and confirm/rescan buttons.

## Dependency removal

`pubspec.yaml` no longer lists `mrzscanner_flutter: ^1.0.0`. `main.dart` no longer calls `Mrzflutterplugin.registerWithLicenceKey`.

## choose_card_dialog.dart no longer calls MRZ functions

The dialog previously branched based on `scanByMrz` from the user's session. If true, it called `_runMrzPassportScanner` (camera) or `_runMrzGalleryScan` (gallery), which invoked `Mrzflutterplugin.startScanner` / `Mrzflutterplugin.scanFromGallery` and navigated to PassportFormPage with a MrzResult. Those helper functions (155 lines total) are deleted.

The Camera and Upload buttons in `showPassportSourceDialog` now unconditionally navigate to the OCR-based scan pages (PassportCardScanPageDomestic or PassportCardScanPageLanding). The domestic card buttons navigate to `DomesticCardScanPage` instead of `CardScanPage`.

## scanByMrz field fully removed

The `scanByMrz` boolean is removed from SharedPreferencesProvider (constant, read/write operations), LoginSession, MobileSettings, AuthRepository.login (LoginResult parsing), and frro_credentials_page.dart (session update). The server still sends `AppScanByMRZ` in login responses, but the client ignores it (**confirmed**).

## API endpoint unchanged

`ApiConstants.login` remains `/api/MRZauthenticate`. Commit `40f5232` reverted an earlier change to `/api/authenticate`—the endpoint name is a server-side artifact that doesn't need to match the client's scanning method.

## OCR scan pages preserved

The OCR-based scan pages introduced in earlier commits are intact: domestic_card_scan_page.dart, domestic_passport_scan_page.dart, foreign_passport_scan_page.dart, and passport_card_scan_page.dart. They use the `camera` package, call OCR extract endpoints, and navigate to form pages with extracted data.

## GitHub Actions workflow

`.github/workflows/build-android.yml` is a new file, not a modification. No steps reference mrzscanner_flutter or patch namespace issues.

## Unrelated changes bundled

The diff includes Firebase integration (firebase_core, firebase_crashlytics, firebase_analytics), theme rebrand (primary color change from `#29ABE2` to `#02132f`, accent color `#b18d4f`), app icon updates, MainActivity package rename (`com.zerosnap.app` → `com.processfriendly`), Firebase config files (google-services.json, firebase_options.dart), session-expired bottom sheet, structured error logging, and the GitHub Actions workflow. These changes are unrelated to the MRZ removal and should have been split into separate PRs. Bundling makes it harder to review each feature independently and increases rollback risk if one feature introduces a regression.
